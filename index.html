GitHub 토큰 연결

비공개 저장소를 읽고 쓰려면 토큰이 필요해요. 이 저장소 하나에만 권한을 주세요.

  1. 토큰 만들기 페이지 열기
  2. Repository access → Only select repositories → ye-in-project
  3. Permissions → Contents → Read and write
  4. 만료일 정하고 생성 → 토큰 복사해서 아래 붙여넣기

토큰은 이 브라우저에만 저장돼요(localStorage). 공용 PC에서는 쓰고 나서 꼭 삭제하세요.
